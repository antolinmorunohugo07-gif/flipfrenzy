    Cómo jugar

    • Gira dos cartas por turno. Si son pareja, se quedan descubiertas.
    • Tienes 5 vidas. Pierdes una cada 3 fallos seguidos.
    • Las parejas seguidas multiplican los puntos (combo).
    • Con combo x3 ganas el ojo 👁 (muestra las cartas 2 s).
    • Con combo x5 ganas el hielo ❄ (para el tiempo 5 s).
    • Cada power-up se usa una vez por partida, con ninguna carta girada.
    • Completa una partida con vidas para desbloquear el siguiente mundo.
